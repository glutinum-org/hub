# Glutinum.Webmidi

Fable bindings for webmidi, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`webmidi`](https://www.npmjs.com/package/webmidi).

The bindings live in the `Glutinum.Webmidi` module, the exports of the package are static members of `Glutinum.Webmidi.Exports`. The `WebMidi` object of the library is `Exports.WebMidi`, the static helpers are on the `Utilities` type.

```fsharp
open Glutinum.Webmidi

let midi = Exports.WebMidi

midi.enable ()
|> Promise.iter (fun midi ->
    for input in midi.inputs do
        printfn "%s" input.name
)

let note = Exports.Note("C#4", Exports.Note.options (duration = 500.0))
let number = Utilities.toNoteNumber "A4"
```

The Chromium of Playwright has no Web MIDI API, so the tests cover the notes, the utilities and the messages, and check that `enable` reports the browser as unsupported. A browser with the API asks the user for permission when `enable` is called.

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.Webmidi.fs` is generated by `./build.sh generate Webmidi` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
