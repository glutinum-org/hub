# Glutinum.CodemirrorState

Fable bindings for @codemirror/state, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`@codemirror/state`](https://www.npmjs.com/package/@codemirror/state).

The bindings live in the `Glutinum.CodemirrorState` module, the exports of the package are static members of `Glutinum.CodemirrorState.Exports`.

```fsharp
open Glutinum

type CodemirrorState = CodemirrorState.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.CodemirrorState.fs` is generated by `./build.sh generate CodemirrorState` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
