# Glutinum.StyleMod

Fable bindings for style-mod, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`style-mod`](https://www.npmjs.com/package/style-mod).

The bindings live in the `Glutinum.StyleMod` module, the exports of the package are static members of `Glutinum.StyleMod.Exports`.

```fsharp
open Glutinum

type StyleMod = StyleMod.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.StyleMod.fs` is generated by `./build.sh generate StyleMod` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
