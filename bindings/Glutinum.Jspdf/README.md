# Glutinum.Jspdf

Fable bindings for jspdf, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`jspdf`](https://www.npmjs.com/package/jspdf).

The bindings live in the `Glutinum.Jspdf` module, the exports of the package are static members of `Glutinum.Jspdf.Exports`.

```fsharp
open Glutinum

type Jspdf = Jspdf.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.Jspdf.fs` is generated by `./build.sh generate Jspdf` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
