# Glutinum.CodemirrorLanguage

Fable bindings for @codemirror/language, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`@codemirror/language`](https://www.npmjs.com/package/@codemirror/language).

The bindings live in the `Glutinum.CodemirrorLanguage` module, the exports of the package are static members of `Glutinum.CodemirrorLanguage.Exports`.

```fsharp
open Glutinum

type CodemirrorLanguage = CodemirrorLanguage.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.CodemirrorLanguage.fs` is generated by `./build.sh generate CodemirrorLanguage` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
