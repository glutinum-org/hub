# Glutinum.CodemirrorView

Fable bindings for @codemirror/view, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`@codemirror/view`](https://www.npmjs.com/package/@codemirror/view).

The bindings live in the `Glutinum.CodemirrorView` module, the exports of the package are static members of `Glutinum.CodemirrorView.Exports`.

```fsharp
open Glutinum

type CodemirrorView = CodemirrorView.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.CodemirrorView.fs` is generated by `./build.sh generate CodemirrorView` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
