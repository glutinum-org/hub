# Glutinum.Dayjs

Fable bindings for dayjs, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`dayjs`](https://www.npmjs.com/package/dayjs).

The bindings live in the `Glutinum.Dayjs` module, the exports of the package are static members of `Glutinum.Dayjs.Exports`.

```fsharp
open Glutinum

type Dayjs = Dayjs.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.Dayjs.fs` is generated by `./build.sh generate Dayjs` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
