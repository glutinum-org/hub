# Glutinum.Yargs

Fable bindings for yargs, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`@types/yargs`](https://www.npmjs.com/package/@types/yargs).

The bindings live in the `Glutinum.Yargs` module, the exports of the package are static members of `Glutinum.Yargs.Exports`.

```fsharp
open Glutinum

type Yargs = Yargs.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.Yargs.fs` is generated by `./build.sh generate Yargs` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
