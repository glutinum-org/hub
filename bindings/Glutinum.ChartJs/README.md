# Glutinum.ChartJs

Fable bindings for chart.js, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`chart.js`](https://www.npmjs.com/package/chart.js).

The bindings live in the `Glutinum.ChartJs` module, the exports of the package are static members of `Glutinum.ChartJs.Exports`.

```fsharp
open Glutinum

type ChartJs = ChartJs.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.ChartJs.fs` is generated by `./build.sh generate ChartJs` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
