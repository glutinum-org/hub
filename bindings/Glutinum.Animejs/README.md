# Glutinum.Animejs

Fable bindings for animejs, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`animejs`](https://www.npmjs.com/package/animejs).

The bindings live in the `Glutinum.Animejs` module, the exports of the package are static members of `Glutinum.Animejs.Exports`.

```fsharp
open Glutinum

type Animejs = Animejs.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.Animejs.fs` is generated by `./build.sh generate Animejs` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
