# Glutinum.Playwright

Fable bindings for playwright, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`playwright`](https://www.npmjs.com/package/playwright).

The bindings live in the `Glutinum.Playwright` module, the exports of the package are static members of `Glutinum.Playwright.Exports`.

```fsharp
open Glutinum

type Playwright = Playwright.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.Playwright.fs` is generated by `./build.sh generate Playwright` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
