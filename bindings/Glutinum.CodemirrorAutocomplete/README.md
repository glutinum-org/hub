# Glutinum.CodemirrorAutocomplete

Fable bindings for @codemirror/autocomplete, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`@codemirror/autocomplete`](https://www.npmjs.com/package/@codemirror/autocomplete).

The bindings live in the `Glutinum.CodemirrorAutocomplete` module, the exports of the package are static members of `Glutinum.CodemirrorAutocomplete.Exports`.

```fsharp
open Glutinum

type CodemirrorAutocomplete = CodemirrorAutocomplete.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.CodemirrorAutocomplete.fs` is generated by `./build.sh generate CodemirrorAutocomplete` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
