# Glutinum.DateFns

Fable bindings for date-fns, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`date-fns`](https://www.npmjs.com/package/date-fns).

The bindings live in the `Glutinum.DateFns` module, the exports of the package are static members of `Glutinum.DateFns.Exports`.

```fsharp
open Glutinum

type DateFns = DateFns.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.DateFns.fs` is generated by `./build.sh generate DateFns` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
