# Glutinum.CodemirrorCommands

Fable bindings for @codemirror/commands, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`@codemirror/commands`](https://www.npmjs.com/package/@codemirror/commands).

The bindings live in the `Glutinum.CodemirrorCommands` module, the exports of the package are static members of `Glutinum.CodemirrorCommands.Exports`.

```fsharp
open Glutinum

type CodemirrorCommands = CodemirrorCommands.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.CodemirrorCommands.fs` is generated by `./build.sh generate CodemirrorCommands` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
