# Glutinum.Chalk

Fable bindings for chalk, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`chalk`](https://www.npmjs.com/package/chalk).

The bindings live in the `Glutinum.Chalk` module, the exports of the package are static members of `Glutinum.Chalk.Exports`.

```fsharp
open Glutinum

type Chalk = Chalk.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.Chalk.fs` is generated by `./build.sh generate Chalk` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
