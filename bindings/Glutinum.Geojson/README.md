# Glutinum.Geojson

Fable bindings for geojson, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`@types/geojson`](https://www.npmjs.com/package/@types/geojson).

The bindings live in the `Glutinum.Geojson` module, the exports of the package are static members of `Glutinum.Geojson.Exports`.

```fsharp
open Glutinum

type Geojson = Geojson.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.Geojson.fs` is generated by `./build.sh generate Geojson` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
