# Glutinum.Leaflet

Fable bindings for leaflet, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`@types/leaflet`](https://www.npmjs.com/package/@types/leaflet).

The bindings live in the `Glutinum.Leaflet` module, the exports of the package are static members of `Glutinum.Leaflet.Exports`.

```fsharp
open Glutinum

type Leaflet = Leaflet.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.Leaflet.fs` is generated by `./build.sh generate Leaflet` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
