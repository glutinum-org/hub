# Glutinum.Codemirror

Fable bindings for codemirror, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`codemirror`](https://www.npmjs.com/package/codemirror).

The bindings live in the `Glutinum.Codemirror` module, the exports of the package are static members of `Glutinum.Codemirror.Exports`.

```fsharp
open Glutinum

type Codemirror = Codemirror.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.Codemirror.fs` is generated by `./build.sh generate Codemirror` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
