# Glutinum.CodemirrorLint

Fable bindings for @codemirror/lint, generated by Glutinum

Generated by [Glutinum](https://github.com/glutinum-org/cli) from [`@codemirror/lint`](https://www.npmjs.com/package/@codemirror/lint).

The bindings live in the `Glutinum.CodemirrorLint` module, the exports of the package are static members of `Glutinum.CodemirrorLint.Exports`.

```fsharp
open Glutinum

type CodemirrorLint = CodemirrorLint.Exports
```

Install the npm package next to the NuGet package, or run `femto` to do it.

The file `Glutinum.CodemirrorLint.fs` is generated by `./build.sh generate CodemirrorLint` in the [hub](https://github.com/glutinum-org/hub), do not edit it.
